# Presentacions

Aquí trobaràs la teoria de cada bloc: els conceptes explicats de manera seguida, amb
definicions formals, propietats i exemples resolts amb dades numèriques. Cada bloc
tanca amb una taula resum i una frase pont cap al següent.

Treballem sempre amb el mateix fil conductor —les nits tropicals a Nulles— perquè cada
eina nova (una taula de freqüències, un gràfic, un estadístic...) s'apliqui sobre un
conjunt de dades que ja coneixes.
